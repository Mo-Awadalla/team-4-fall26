# Emoji catalog

The picker uses the free [Unicode emoji data feed](https://www.unicode.org/Public/emoji/latest/emoji-test.txt). This snapshot contains every fully qualified emoji and standalone component in Emoji 18.0, organized by Unicode group. Each entry contains the glyph and its English name. The browser loads the local catalog on first use. Glyph appearance depends on the operating system’s emoji font. The Unicode license is included alongside the data.
